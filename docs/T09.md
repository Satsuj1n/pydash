# T09 — Planejamento de Cenários de Teste

## Objetivo
Definir cenários reprodutíveis para comparar ABRs.

## Parâmetros fixos
- MPD: BigBuckBunny 1s
- `buffering_until=5`, `max_buffer_size=60`, `playbak_step=1`
- `traffic_shaping_profile_interval=5`
- `traffic_shaping_seed=1` (sempre)

## Cenários
| ID | `traffic_shaping_profile_sequence` | Duração alvo | Objetivo |
|----|------------------------------------|--------------|----------|
| C1 | `L`                                | ~10 min      | Baixa banda estável |
| C2 | `M`                                | ~10 min      | Média banda estável |
| C3 | `H`                                | ~10 min      | Alta banda estável |
| C4 | `L,M,H`                            | ~10 min      | Variação periódica |

## Procedimento (PowerShell)
```powershell
& .\.venv\Scripts\Activate.ps1
$env:PYTHONPATH = (Get-Location).Path

function Run-Cenario($seq, $label) { 
  (Get-Content .\dash_client.json -Raw) `
    -replace '"traffic_shaping_profile_sequence"\s*:\s*"[^"]+"', ('"traffic_shaping_profile_sequence":"{0}"' -f $seq) | `
    Set-Content .\dash_client.json

  $ts = Get-Date -Format 'yyyyMMdd_HHmmss'
  $out = ".esults\{0}_$ts" -f $label
  New-Item -ItemType Directory $out -Force | Out-Null
  python .\main.py *> "$outun_$ts.log"
  robocopy .esults $out /E /XD $out > $null
  Copy-Item .\dash_client.json $out
}

Run-Cenario 'L'      'C1_L'
Run-Cenario 'M'      'C2_M'
Run-Cenario 'H'      'C3_H'
Run-Cenario 'L,M,H'  'C4_LMH'
```

## Aceite (T09)
- Quatro cenários definidos e executáveis pela troca do campo `traffic_shaping_profile_sequence`.
- Resultados arquivados em `results/<CENARIO>_<timestamp>`.
